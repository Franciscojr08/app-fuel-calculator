# App Fuel Calculator

**Atividade acadêmica desenvolvida para a faculdade.**

O **App Fuel Calculator** é uma aplicação móvel desenvolvida com React Native, criada como parte de uma atividade acadêmica. O objetivo é calcular o consumo de combustível de veículos, permitindo ao usuário comparar o custo-benefício entre gasolina e etanol.

## 🛠 Tecnologias Utilizadas

- React Native
- JavaScript
- Expo

## 📁 Estrutura do Projeto

- `App.js` – Componente principal da aplicação
- `assets/` – Recursos como imagens e ícones
- `.expo/` – Arquivos de configuração gerados pelo Expo
- `package.json` – Gerenciador de dependências e scripts
- `app.json` – Configurações do projeto Expo
- `.gitignore` – Arquivos ignorados pelo Git
- `babel.config.js` – Configuração do Babel
